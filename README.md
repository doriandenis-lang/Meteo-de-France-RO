# Météo France & Outre-mer

Page web de météo en direct pour les 13 régions de France métropolitaine et les 5 régions d'outre-mer (Guadeloupe, Martinique, Guyane, La Réunion, Mayotte).

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation ni serveur nécessaire.

## Fonctionnalités

- Conditions actuelles et mini/maxi du jour pour chaque chef-lieu de région
- Heure locale et fuseau horaire pour l'outre-mer
- Fiche détaillée : vent, rafales, humidité, pression, pluie, UV, lever/coucher du soleil
- Courbe des 24 prochaines heures et tendance sur 7 jours
- Recherche de n'importe quelle commune française (métropole et outre-mer)
- Actualisation automatique toutes les 15 minutes, thème clair/sombre, affichage mobile

## Données

[Open-Meteo](https://open-meteo.com/) : API publique gratuite, sans clé (prévisions et géocodage).
